# Этап 4: почта (11.09.2026)

## Что сделано

Модуль `app/Mail/`: `Account` (доступы в базе, пароли `encrypted`), `Folder`,
`Thread`, `Message`, `Address`, `Attachment`, `Template`, `Candidate`.
Сервисы: `Imap` (протокол webklex: папки со STATUS, UID по диапазону, сырые
письма пачками по бюджету байт, флаги, APPEND с UIDPLUS, IDLE), `Parser`
(iconv для заголовков, имена вложений из сырого письма), `Threads`
(References → тема+собеседники за 90 дней → новая), `Sync` (ключ
`(folder, uid_validity, uid)`, двойник по Message-ID переезжает, письма
больше 25 МБ — только заголовки), `Sender` (SMTP из строки ящика через
`Mail::build`, Message-ID выписан до отправки, APPEND в «Отправленные»),
`Composer` (ответ/всем/переслать/новое, файлы из `mail/outbox/`),
`BodyRenderer` (iframe `sandbox` + CSP, внешние картинки по кнопке),
`ConnectionTester`.

Процессы: `mail:sync` каждую минуту (`runInBackground` + advisory lock),
`mail:watch` — сервис compose `mail-watch`: надсмотрщик держит по процессу
IDLE на ящик, `mail:reconcile` в 4:10. Джобы почты — на соединении
`database-long` (retry_after 2100), очереди `mail` и `long` слушает
`queue-long`.

Кандидаты: `Extraction/Extractor` по домену настоящего отправителя
(`QuotationStripper::forwardedSender`) → шаблон (Tinkoff, Sovcombank,
Energogarant, Insight, Generic), `CodeMatcher` с формами кодов убытка,
`looksLikeOffer` = код + машина или машина + цена. `PromoteCandidate` →
черновик через `CreateOffer`/`UpdateOffer` (марка через `Brand::resolve`,
страховая по имени, `claim_ref`), ветка привязана, `ImportCandidateMedia`
на очереди `long` (документы как есть, фото через `PhotoIngest`, zip/7z
`ArchivePhotoExtractor`, листы со снимками `PageScanCropper` — оба
перенесены из донора без изменений в алгоритме).

Экраны: `/admin/mail` (пресеты, поиск, ящики), `/admin/mail/{thread}`
(письма, вложения, привязка к офферу, флаг, «не прочитано»),
`/admin/mail/new` и `/admin/mail/{thread}/reply/{message}` — страница
с Trix (`ui.editor`), файлы через `photos_controller` в `#compose-files`;
`/admin/mailboxes` (+ «Проверить», синхронизация, папки), `/admin/templates`,
`/admin/kandidaty`. Этап маршрута получил `template_id`: на карточке оффера
кнопка «Письмо страховой» открывает письмо с подстановками
(`MailController::placeholders`). Таб «Разговоры» стал «Почта».

## Как проверялось

Локально без реального ящика: `/tmp/claude-501/imapserver.py` — IMAP на
Twisted (порт 1143, пользователи `offer`/`deal`, пароль `parol`, письма
подкладываются файлами в `imapdrop/<user>/*.eml`), mailpit на 1025/8025.
Прогнано: письмо Совкомбанка с фото, СТС, zip и pdf → синк → разбор →
кандидат со всеми полями → черновик 1003 с 3 фото и 2 документами →
ответ с вложением → mailpit получил, копия легла в Sent через APPEND →
повторный синк не завёл дубля. Dovecot из brew под macOS без root не
поднимается (setrlimit) — не тратить время.

## Грабли

- Без строки `* SEARCH` webklex отдаёт вместо данных строку `OK` —
  `intval` даёт UID 1. В `Imap::uids` берём только числа.
- Eloquent пишет дату в её собственном поясе, не переводя в пояс
  приложения: даты писем приводятся к `app.timezone` в `Parser`. Заодно
  оказалось, что `config/app.php` держал `'UTC'` литералом и `APP_TIMEZONE`
  не читался — исправлено, на проде время теперь московское.
- Trix схлопывает `<p>` внутри `<blockquote>` — цитата собирается через `<br>`.
- Класс не может называться `Exit`; в почте нет таких, но `Imap` — не
  `IMAP` (константы webklex импортированы под другим именем).
