# Страхователь в письмах: как пишут телефон и имя (выборка 29.09.2026)

Вытянул с прода 179 входящих писем стоянки со словами «клиент / страхователь / ГОТС / вывоз / передача»
(149 АльфаСтрахование, 13 ВСК, 11 mail.ru, по паре РГС, МФК-Торг, СОГАЗ). 168 из них упоминают клиента,
у 141 есть телефон в нужном месте, у 128 из них рядом имя.

## Как выглядит у Альфы (95 % заявок на приём)

Абзац один и тот же, телефон с именем — отдельной строкой сразу после просьбы:

```
Просьба связаться с клиентом, для согласования даты и времени передачи ГОТС.
8-985-171-19-90 Александр
Как только клиент сдаст ТС, просьба прислать в цветном скане …
```

Варианты той же строки: `Михаил 8-916-987-12-37` (имя до), `8-903-660-97-52 - Игорь`, `8-903-286-39-38- Умарбек`,
`Михаил – 89119680042`, `Юр. л. Представитель Евгений 8-915-185-63-65`, `Представитель собственника Михаил 8-977-…`,
`Представитель по доверенности Владимир 8-926-… или 8-903-…`, `Представитель8-910476-65-41 Артем` (без пробела),
`8-900-690-72-02 Анастасия/ 8-950-693-42-43 Александр - представитель` (два человека),
`Контактное лицо со стороны ПАО "Аэрофлот" - Хитров Игорь Игоревич, тел. +79036722323`,
`Контакт представителя Будаев Ярослав +79269103004`. Иногда строка с телефоном стоит **до** фразы про клиента
(«Добрый день! / 8-985-280-90-84 Анастасия / Как только клиент сдаст ТС…»). Бывает без имени: «Контакт 8 909 967 62 58».

Подпись сотрудника страховой всегда после «С уважением,» (Ткаченко Евгений … тел.: (495) 788-09-99 доб. 600428;
Чеченев Руслан / тел. 89653313811) — её телефон брать нельзя.

ВСК пишет иначе (длинные письма, телефон клиента в скобках или строкой «Контактный телефон / 7-965-188-07-18»),
РГС и СОГАЗ — единичные письма без телефона клиента.

## Правило (`Template::insured`)

Текст разбирается по строкам. Ищется строка со словом клиент/страхователь/собственник/владелец/представитель/контакт;
телефон берётся из неё же, из строки выше или из трёх следующих, пока не встретилось «С уважением». На найденной
строке первый номер — телефон страхователя; имя — первые слова с заглавной после номера (до следующего номера),
иначе последние слова с заглавной до номера; служебные слова (Юр. л., Представитель, Контактное лицо со стороны,
ПАО, тел.) выкидываются; не больше трёх слов (Фамилия Имя Отчество). Проверено скриптом на всей выборке:
141 телефон, 128 имён, ложных срабатываний на подписи нет.
