# Дизайн и вёрстка стоянки заново — 26.09.2026

Дмитрий прошёлся по park.xcar и назвал халтурой: страницы разной ширины, плитки-итогы «0 счетов · 0 ₽ ·
0 контрагентов» на каждом экране («главное, что выдаёт нейросеть»), письма узкой колонкой сбоку, «Сегодня» —
копия заявок, «Из писем» без фото, заявка из письма размазана по трём экранам, кадры из письма перемешаны
с кадрами приёма. 90 % пользователей — с телефона.

## Что сделано

- **Одна ширина.** `narrow` снят со всех экранов стоянки и с редактора письма; страницы объекта — одна колонка
  на телефоне, от `lg` — `1fr + 22rem` (заявка: история справа; новый счёт: «Кому» справа; редактор письма:
  вложения справа). Чипы с длинным адресом ужимаются многоточием (`x-ui.place` → `truncate`), длинные записи
  осмотра — текстом, не чипом (это и растягивало `/cars/{id}` на 375 px).
- **Плиток-итогов нет.** `x-ui.stat` убран с долгов, закрытия, вендора в CRM, импорта закупок; экран
  `/money/summary` («Месяц») удалён вместе с `Ledger::month`. Сумма выбранного — в кнопке: «Выставить 3 счета
  на 2 900 ₽» (`sum_controller`).
- **«Сегодня» убран.** `/` — заявки; таб «Заявки»; пресет «Просрочено» красной пилюлей (`tones` у тулбара),
  у ТС — пресет «Стоят долго». `Park\Today::build` остался дайджесту.
- **Письма в окне.** `x-mail.window` + `x-mail.window-button` вместо `x-mail.aside`: `x-ui.sheet tall` —
  на телефоне шторка, от 640 окно 48rem по центру, письма целиком с вложениями. Тело письма — тёплый лист
  с полем 12px. Механизм `inflow` остался блоку сделки.
- **Почта таблицей.** `x-mail.thread-row`, вид по умолчанию — таблица (`ListPrefs` с `rememberTable`),
  строки со свайпом — по выбору; строка открывает окошко ветки `/mail/{thread}/peek` со всеми письмами
  (помечает прочитанным), «Открыть» — страница. «Назад» с ветки на стоянке вёл в `/work/mail` — починено.
- **«Из писем» с фото.** `Candidate` — `HasMedia`; `ImportCandidateFiles` из `ExtractCandidate` закрепляет
  вложения письма (`PinThread::message`) и импортирует кадры; карточка, окошко и форма заявки показывают их до
  заведения; при «Завести» кадры переезжают к ТС/предложению (`Candidate::moveMediaTo`), `ImportThreadFiles`
  по `sha` не дублирует. `mail:candidate-files` — разово по открытым кандидатам.
- **Заявка одной страницей.** `x-park.vehicle-fields` — те же поля ТС на странице заявки (компактная
  карточка, `PUT /cars/{id}` с `back`; повреждения и негабарит трогаются только когда форма их прислала);
  форма «Завести» — те же поля + доставка + «Из письма». Приём: карточка «Из письма» (только смотреть,
  `x-ui.photos readonly`) и «При приёме» (слоты), подпись — последней; выдача: «При приёме» и «При выдаче».
  В плашке: главное действие, «Письма N», отмена круглой кнопкой.
- Мелочи: номер убытка не дублируется рядом с названием ТС без марки; действия счёта (PDF, акт, печать,
  отправить, изменить) — в шторке «⋯»; карточка «Письма» на ТС больше не зависит от наличия заявок.

## Правила, которые из этого вышли

- Плиток-итогов (`x-ui.stat`) не рисуем: число, которое нужно, — в чипе рядом с делом или в кнопке.
- Читать письма — в окне (`x-mail.window`), не в колонке и не на отдельной странице.
- На стоянке нет `narrow`: одна ширина, вторая колонка от `lg` только тому, что читают.
