# Покупатели менеджеров — 16.09.2026

Что сделано и почему так — подробно в CLAUDE.md, раздел «Роли, цены, покупатели».
Здесь — решения владельца и грабли.

## Решения владельца

- Покупатель видит только открытое ему; галереи, закупок, чата, шеринга у него нет.
- Закупки покупателям не открываются; у закупок круг менеджеров не сужаем.
- Каждый оффер — свой круг менеджеров, по умолчанию все.
- Интерес — кнопка с необязательным комментарием, можно снять; уведомление
  только менеджеру покупателя, сотрудникам — нет (в CRM видно списком).
- Пригласительная ссылка многоразовая, `xcar.ru/i/{code}`, менеджер решает,
  указывает ли покупатель телефон и почту (по умолчанию — нет: у нас нет его
  контактов, это главный аргумент менеджеру).
- Вход одним полем: логин / телефон / почта. Логин латиницей.
- Менеджер работает в кабинете на сайте, в CRM его нет.
- Посетители (visitor) удалены миграцией — тестовые. Код допуска по заявке
  остался, не используется.
- Заявленная цена восстановлена (донор — `publish_price`); граница подтверждения
  считается от неё.

## Грабли

- `collect()->map('intval')` — второй аргумент map (ключ) уходит в intval как
  основание системы счисления: второй элемент превращается в 0. Только
  `fn ($v) => (int) $v`.
- Scope и метод не могут называться одинаково: `scopeVisibleTo` + `visibleTo()`
  → «Non-static method cannot be called statically». Экземплярный — `isVisibleTo`.
- Шторка с POST-формой: редирект на тот же адрес — morph, `open` у диалога
  морф бережёт (для блока сделки), и шторка висела после сохранения у всех
  форм проекта. Теперь `app.js` закрывает её на успешном `turbo:submit-end`,
  если новый HTML не просит открыть снова (`data-sheet-open-value`).
- `x-slot` внутри `@isset` в компоненте — «unexpected end of file»: слот
  передаётся всегда, пустой шелл выбрасывает сам (`$actions->isEmpty()`).
- Частичные уникальные индексы Eloquent не знает — показы вставляются
  `insertOrIgnore`.

## Проверено глазами (local)

Регистрация по ссылке с транслитом логина → пустая лента с менеджером;
показ пачкой из режима выбора → уведомление «открыл вам 2 автомобиля» → лента
покупателя из двух машин с одной ценой; интерес с комментарием → менеджеру
тост и строка на странице оффера; ссылка на пароль от админа → новый пароль →
вход по логину; повторно ссылка «не действует»; `/register` POST — 405.
