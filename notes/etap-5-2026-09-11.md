# Этап 5: чаты и шеринг (11.09.2026)

## Чаты — `app/Chats/`

`Chat` = пара (оффер, участник), сотрудники отвечают, не становясь
участниками. `Message.seq` — номер в чате под `lockForUpdate` строки чата:
догон «всё после N» идемпотентен. `author_kind` — факт на момент письма.
Файлы — `chat_files` на диске `private`, только фото и PDF, отдаются с
`nosniff`, `inline` для картинок и PDF. Постороннему — 404.

Экран один на обе стороны: `x-chat.box` + `chat_controller.js`; на витрине
он в шторке страницы оффера (`?chat=1` открывает сразу после `POST
/offers/{n}/chat`), у сотрудников — `/admin/chats/{chat}` целой страницей
(отвечают часто). Концы общие: `GET/POST /chats/{chat}/messages`
(HTML-фрагмент новых сообщений после `after`), `GET /chats/{chat}/files/{file}`.
Live: `ChatMessagePosted` → событие `chat {chat, seq}` в личную тему
участника и в `staff`, `live_controller` пробрасывает его DOM-событием
`live:chat`, чат догоняет. Уведомление — только о первом непрочитанном
(`unread_for_* === 1`), дальше человек уже в чате.
Раздел «Почта» получил переключатель «Письма | Чаты», бейдж таба — сумма.

## Шеринг — `app/Offers/Share/`

`PdfWriter` перенесён из донора как есть: страница на фото по размеру
кадра, JPEG байтами (DCTDecode), водяной знак полосой средствами PDF
(Helvetica, без кириллицы). `SharePdf` кодирует выбранные фото в базовый
JPEG 1280 q72 через GD, кэширует файл по набору и знаку в
`private/share/{offer}/`. `Caption::fields` — строки текста с флагом
«включено по умолчанию»: цена только тем, кому видна, нижняя от страховой —
только сотруднику и выключена.

Клиент `share_controller.js`: текст собирается из отмеченных строк (цена
одной строкой «нижняя → верхняя» + метка НДС), кладётся в буфер с U+2028
до первого `await`, файл уходит отдельным `navigator.share({files})`.
Знак снимает только сотрудник; с витрины он всегда.

## Проверено

Локально: чат менеджер ↔ админ с фото, счётчики непрочитанного, уведомления
обеим сторонам; PDF из трёх фото 54 КБ, полоса со знаком отрисована (sips →
png). Шторка шеринга на 375px: строки, превью, сетка фото, статус «PDF готов».
На телефоне проверить `navigator.share` с файлом — на iPhone Safari файл
уходит в Telegram/WhatsApp (проверено в старом проекте 24.08.2026).
