# Этапы 0–2: каркас, оболочка, офферы (11.09.2026)

Проект начат с нуля, см. `~/.claude/plans/tender-jumping-quokka.md` и `CLAUDE.md`.

## Сервер

`ssh xcar-next` → 200.169.180.17, Ubuntu 22.04, 2 ядра, 4 ГБ, 47 ГБ. IPv4
живой: Telegram и Let's Encrypt отвечают с сервера напрямую. Настроен
`deploy/server-setup.sh`: только ключ, ufw 22/80/443, docker 29, пароль root
сменён (в `CONNECT.local.md`). Первая выкладка `deploy/deploy.sh` — сайт
по `http://200.169.180.17`, Octane/FrankenPHP в режиме воркера, хаб Mercure.

Грабли первой выкладки:
- `head -c` в генераторе ключей под `pipefail` ронял скрипт молча — `openssl rand -hex`.
- `run --no-deps app … migrate` до старта postgres — теперь `up -d --wait postgres` перед миграциями.
- `ACME_EMAIL` пустой строкой из compose перебивал дефолт Caddy (`{$X:default}`
  работает только для незаданной переменной) — дефолт перенесён в compose.

## Что сделано

- Laravel 13, Postgres на всё, Turbo + Stimulus (без Alpine), prefetch на
  `touchstart`, view transitions по `data-turbo-visit-direction`.
- Пользователи: роли, разделы доступа, вход по телефону/почте, passkeys
  (`laragear/webauthn` + `@laragear/webpass`; работает только на HTTPS,
  по IP не проверить).
- Кит: `resources/views/components/ui/*` + контроллеры Stimulus; витрина `/admin/ui` локально.
- Офферы: справочники из CSV, медиатека (webp 1600, конверсии), редактор
  секциями, каталог, страница машины, ставки, интерес, избранное, сделка.
