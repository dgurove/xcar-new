# Этап 7: совместные закупки (11.09.2026)

## Модуль `app/Purchases/`

`Purchase` (номер, состояние draft/open/closed/archived, срок цен), `Car`
(ключ строки — ДЛ поставщика, свой `ref` наружу, характеристики, цены
поставщика, ссылки, состояния выкачки `ImportState`, `locked_fields` —
правленое руками не перетирается), `Offer` (цена покупателя, одна живая на
человека), `Restriction` (какие категории кому не показывать). Своя таблица,
а не колонка в офферах: закупочной цены на публичной модели нет.

`XlsxReader` (openspout 5, колонки по заголовку, формулы в ссылках
останавливают строку), `Importer` (повторный импорт находит своё по ДЛ),
`Carcade` (`__NEXT_DATA__` карточки, WebDAV облака с браузерным UA, архивы
папочным `?accept=zip`, всё через `CARCADE_PROXY`), джобы `FetchSpecs` и
`FetchPhotos` (очередь `long`, потолок 40 кадров, `Gone` — снято у
поставщика), `Export` (тот же файл с заполненным «Предложением клиента» и
листом всех цен).

Действия: `CreatePurchase`, `ImportFile` (+ `refetch`), `ChangePurchaseState`
(открытие → уведомление менеджерам), `PlaceOffer`, `WithdrawOffer`,
`ChooseOffer` (уведомление выбранному), `UpdateCar`.

## Экраны

Витрина `/zakupki` — список открытых; `/purchases/{n}` — ведомость: срок,
«пройдено N из M» с полосой, пресеты «без моей цены / с моей ценой / с фото»,
категории, поиск по ДЛ/VIN/марке, сортировка по порядку файла; строка
машины — без цен поставщика, со своей ценой числом. `/purchases/{n}/{ref}` —
карточка с фото, характеристиками, формой цены и стрелками к соседям по тому
же отбору (отбор едет в адресе, машина из него не выпадает).

Панель `/admin/zakupki`: список, создание шторкой; `/admin/purchases/{n}` —
итоги (машин, с фото, с ценами, сумма лучших и разница к нашей), загрузка
xlsx → превью со статистикой и проблемными строками → «Завести» → выкачка
фоном; выгрузка xlsx; пресеты «с ценами / требуют внимания / без фото»;
`/admin/purchases/{n}/{ref}` — редактор машины, фото (загрузка, «забрать все
из облača»), цены покупателей с «Выбрать»; `/admin/purchases/ogranicheniya` —
чипами по менеджерам.

## Проверено локально

Файл из трёх строк (одна с формулой) → превью «3 / 2 новых / 1 не
прочиталась» → импорт → выкачка по несуществующим ссылкам корректно даёт
«снято» и «ошибка 503» → открытие приёма → менеджер видит список без цен,
называет цену → «пройдено 1 из 2» → админ выбирает → xlsx с ценой в колонке
и листом предложений.

Живые ссылки Carcade не пробовались (пробы только с мака и не с прода —
память `carcade-ban-and-proxy`); на проде нужен `CARCADE_PROXY` в
`.env.app`, пока его нет — выкачка будет падать в «ошибку», машины при этом
видны с данными из файла.
